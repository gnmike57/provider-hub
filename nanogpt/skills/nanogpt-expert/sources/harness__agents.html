Experimental browser integration

WebMCP on NanoGPT chat pages

Browsers with WebMCP support can discover structured NanoGPT tools directly from an open chat page. The integration is progressively enhanced: unsupported browsers receive no extra UI or API requests and do not load the WebMCP tool definitions.

WebMCP browser guide
get_chat_state

Read the selected model, chat mode, and whether a draft exists—without reading its text.

find_text_models

Search the public NanoGPT text-model catalog by model ID.

draft_chat_message

Prepare text in the composer, but never send it or start a paid request.

Monitoring is anonymous and aggregate. NanoGPT counts capable-browser reach, tool-registration success or failure, and actual invocation lifecycle results so reach can be compared with confirmed use. NanoGPT does not record WebMCP arguments, outputs, prompt text, conversation IDs, agent names, registration errors, or session IDs. WebMCP does not expose a reliable callback for an agent merely inspecting the tool list, so capable reach is reported separately from invocations.
